# Fold-2 equal-weight decomposition and canonical-vs-passive tests -- corrected costs

> Eval-only deterministic replays on the fold-2 test window (2015-2017); no training, fold 4 never loaded. Generated by `analyze_ew_decomposition.py`. Both EW replays reproduce the stored values in `baselines_corrected.csv` exactly (asserted).

## 1. What differs between the two EW benchmarks

| | equal_weight_k5_band010 | ew_matched_execution |
|---|---|---|
| target | 1/N | 1/N (constant action) |
| decision cadence | 5 days (strategy-side) | 5 days (env `decision_frequency_days`) |
| no-trade band | per asset, 0.10 vs actual drifted weight (strategy-side) | per asset, 0.10 vs actual drifted weight (env `no_trade_band`; same rule) |
| gross cap 2.0 | n/a | applied; never binds for a 1/N long book |
| action smoothing | none | beta 0.1: w_t = 0.9 w_(t-1) + 0.1 a_t from flat |

Smoothing is the only material difference (the cadence phase differs by one step: strategy decides on steps 0, 4, 9, ...; env on 0, 5, 10, ...). The third row below removes only smoothing from the matched execution.

| fold 2 | net return | turnover/day | cost/NAV | mean invested | invested d0-40 | invested d40+ |
|---|---:|---:|---:|---:|---:|---:|
| equal_weight_k5_band010 | +0.2330 | 0.0013 | 0.0035 | 1.003 | 1.004 | 1.003 |
| ew_matched_execution | +0.1933 | 0.0011 | 0.0029 | 0.723 | 0.131 | 0.755 |
| ew_matched_minus_smoothing | +0.2330 | 0.0013 | 0.0035 | 1.003 | 1.004 | 1.003 |

Removing smoothing reproduces k5_band010 exactly, so the 4.0-point gap is entirely smoothing. It is not a cost drag (the smoothed book has lower cost and turnover): it is an under-investment drag. From flat, the smoothed target 0.2(1-0.9^k) first clears the 0.10 band after ~7 decisions (~35 trading days), and afterwards the residual gap to 1/N rarely exceeds the band, so the book stays ~76% invested -- a cash drag in a rising window.
